# Idiomatic Go Skill

Use this skill when reviewing or implementing Go code.

## Checks

- simple package boundaries
- clear error handling
- context propagation
- no unnecessary abstraction
- interfaces defined by consumers
- no panic for normal control flow
- no goroutine leaks
- no data races
- table-driven tests where useful
- standard library preferred when practical

## Output

Return concrete findings with file path, reason and suggested change.
