# Code Review Skill

Use this skill when reviewing code changes.

## Procedure

1. Identify the task intent.
2. Inspect the changed files.
3. Compare implementation against the task.
4. Search for correctness bugs.
5. Search for security risks.
6. Search for performance regressions.
7. Search for maintainability issues.
8. Require validation evidence.

## Output

Return:

- blocking issues
- critical risks
- suggested fixes
- validation commands
- verdict
